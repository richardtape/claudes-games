# Claude's Games

A shelf of small single-player browser games, one made by Claude on each visit.

**Play online: https://richardtape.github.io/claudes-games/**

```sh
npm install      # once: installs playwright-core for the headless checks (uses your Chrome)
npm start        # http://localhost:8642
```

Open http://localhost:8642 and pick a cartridge. Progress and best scores are stored in your
browser.

To get a new game, open a Claude Code session in this folder and ask for one. `CLAUDE.md`
explains the setup, the tools and the conventions Claude follows.

The public repository is a clean copy generated by `npm run deploy` (`scripts/deploy.mjs`); please don't edit it directly.
